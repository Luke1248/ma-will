# HSK Flashcards 📇🇨🇳

A spaced-repetition flashcard app for memorizing **HSK 1–6** Chinese vocabulary
(all **5,000 words**). It's a Progressive Web App (PWA), so you can add it to
your iPhone/iPad Home Screen and use it **fully offline** like a native app — no
App Store, no install, no account.

## 📲 Install it now (no setup)

The repo is public, so the app is already served over HTTPS by **githack** —
no GitHub Pages step, no hosting to configure. On your **iPhone/iPad**, open
this link in **Safari**:

```
https://rawcdn.githack.com/Luke1248/ma-will/711e087/hsk-flashcards/index.html
```

Then tap **Share** (the square-with-an-arrow) → **Add to Home Screen** → **Add**.
You'll get an "HSK" icon that opens full-screen and works offline.

> The `/711e087/` part pins a fixed version (a commit). For your own clean,
> always-latest URL, see **Hosting on GitHub Pages** below.
>
> Note: do **not** use `cdn.jsdelivr.net` for the page — jsDelivr serves `.html`
> as plain text, so the browser shows the source code instead of the app.
> githack serves it with the correct `text/html` type so it renders.

## What it does

- **Spaced repetition (SM-2 algorithm)** — the same memory-over-time system Anki
  uses. Cards you find easy come back in days, then weeks, then months; cards you
  miss come back in minutes. This is what "checks your memory over time."
- **All HSK 1–6 vocabulary** — 150 / 150 / 300 / 600 / 1,300 / 2,500 words, each
  with simplified hanzi, tone-marked pīnyīn, and an English definition.
- **Per-level study** — pick which HSK levels you're working on.
- **Daily new-card limit** so you don't burn out (default 10/day).
- **Three study directions** — Hanzi→Meaning, Meaning→Hanzi, or Mixed.
- **Audio** — tap 🔊 to hear the word (uses your device's Chinese voice).
- **Progress, streaks, and stats**, saved on your device.
- **Export / import** your progress as a JSON backup.
- **Works offline** once loaded, and installs to the Home Screen.

## Put it on your iPhone / iPad

This repo includes a **GitHub Actions workflow**
(`.github/workflows/deploy-pages.yml`) that **auto-deploys the app to GitHub
Pages** on every push that touches `hsk-flashcards/`.

**One-time setup** (GitHub doesn't let the workflow enable Pages by itself):

1. In this repo on GitHub, go to **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.

That's the only manual step. From then on:

3. Any push to `main` (or this branch) runs the **Deploy HSK Flashcards to
   GitHub Pages** workflow under the **Actions** tab. Re-run the latest run once
   after enabling Pages so the first deploy goes out.
4. When it finishes (~1 minute), your app is live at:

   ```
   https://<your-username>.github.io/<repo>/
   ```

   For this repo that's `https://Luke1248.github.io/ma-will/`. The exact URL is
   shown in the workflow run summary (the `github-pages` environment) and under
   **Settings → Pages**.
5. **On your iPhone/iPad**, open that URL in **Safari** (must be Safari for
   install to work), tap the **Share** button (the square with an arrow), then
   **Add to Home Screen**. Tap **Add**.

You'll get an "HSK" icon on your Home Screen that opens full-screen, runs
offline, and keeps your progress between sessions.

> Tip: open the app once while online so it can cache everything; after that it
> works with no connection.

## Run it locally (optional)

Service workers need `http://` or `https://` (not `file://`), so use any static
server from inside the `hsk-flashcards/` folder:

```bash
cd hsk-flashcards
python3 -m http.server 8099
# then open http://localhost:8099/
```

## How studying works

1. The home screen shows how many cards are **due** (scheduled reviews + new
   cards for today). Tap **Start studying**.
2. Read the prompt, try to recall the answer, then tap to **Show answer**.
3. Rate how it went:
   - **Again** — you missed it; it comes back in ~1 minute.
   - **Hard** — barely; shorter next interval.
   - **Good** — you knew it; normal interval growth.
   - **Easy** — instant; longer interval.
4. The app schedules each card's next review automatically. Come back daily and
   clear your due pile — that's the whole method.

Keyboard shortcuts (iPad with keyboard / desktop): **Space** to reveal,
**1/2/3/4** to grade Again/Hard/Good/Easy.

## Data & privacy

- Everything runs locally in your browser. There is **no server and no account**;
  your progress lives in your device's local storage. Use **Settings → Export
  progress** to back it up or move it to another device.
